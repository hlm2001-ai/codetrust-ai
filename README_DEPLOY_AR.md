# CodeTrust AI — نشر الموقع على Streamlit Community Cloud

هذه ملفات النشر الخاصة بموقع CodeTrust AI ثلاثي الأبعاد.

## الملفات اللازمة

- `app.py` — واجهة الموقع وتشغيل التحليل.
- `requirements.txt` — المكتبات التي تثبتها Streamlit.
- `frozen_v3_prompt.json` — نص Enhanced V3 المُجمّد.
- `.streamlit/config.toml` — ألوان الموقع وإعداداته.
- `.gitignore` — يمنع إضافة بعض ملفات الأسرار المحلية.

**مهم:** هذه الواجهة تستخدم Enhanced Prompt V3 للتشخيص؛ مقارنة البرومبتات الخمسة تمت في تجربة Google Colab منفصلة. لا تخلطي بين واجهة العرض ونسخ تجارب البحث.

## النشر خطوة بخطوة

1. أنشئي حساب GitHub على https://github.com إذا لم يكن عندك حساب.
2. أنشئي Repository جديدًا باسم `codetrust-ai` واختاري Private إن كنت تريدين إظهار الموقع للدكتور فقط.
3. افتحي المستودع واضغطي **Add file → Upload files**.
4. **فكّي ضغط ZIP أولًا، ثم ارفعي الملفات والمجلد `.streamlit` داخل المستودع؛ لا ترفعي ZIP كما هو.** راجعي أن `app.py` في جذر المستودع.
5. اذهبي إلى https://share.streamlit.io وارْبطي حساب GitHub.
6. اختاري **Create app → Yup, I have an app**، ثم Repository: `codetrust-ai`، Branch: `main`، Main file path: `app.py`.
7. من إعدادات النشر المتقدمة **Advanced settings → Secrets** اكتبي سطرًا بصيغة TOML التالية، وضعي قيمة المفتاح **داخل إعدادات الموقع فقط**:

   ```toml
   OPENAI_API_KEY = "YOUR_SECRET_KEY_HERE"
   ```

8. اضغطي Deploy. إذا كان الموقع Private، ضعي إيميل الدكتور ضمن مشاهدي التطبيق من إعدادات المشاركة؛ وإلا لن يتمكن من فتحه.
9. جربي رابط الموقع من متصفح آخر، ثم احتفظي بلقطة شاشة وفيديو قصير لعرض المشروع.

## تنبيهات

- لا ترفعي المفتاح الفعلي ولا `.streamlit/secrets.toml` إلى GitHub، ولا تضعيه داخل البحث أو الفيديو.
- استضافة Streamlit مجانية، لكن **استدعاءات OpenAI API قد تكون مدفوعة**. تحققي من إعدادات الإنفاق قبل مشاركة رابط يعمل للآخرين.
- قد يدخل الموقع وضع السكون عند عدم الاستخدام؛ افتحيه واختبريه قبل العرض.
- الموقع لا يشغّل كود Python المرسل؛ يرسله كنص إلى نموذج GPT-4.1 mini لتحليله.
- ملف `benchmark_with_references.json` ونتائج التقييم ليست مطلوبة لتشغيل الموقع؛ احتفظي بها داخل حزمة البحث ولا ترفعيها إلى مستودع الواجهة العام.
